# GOLD Chicken AI 광고 프로젝트

생성형 AI를 활용하여 가상의 후라이드 치킨 브랜드 **GOLD Chicken**의 광고 영상을 제작한 프로젝트입니다.

## 프로젝트 목표

**“지친 하루 끝에 만나는 작은 보상”**을 콘셉트로, 퇴근 후 지친 직장인이 GOLD Chicken을 통해 기분이 전환되는 과정을 표현했습니다.

## 제작 파이프라인

**기획 → 프롬프트 작성 → 이미지 생성 → 영상 변환 → 오디오 생성 → 최종 편집**

## 사용 도구

* **ChatGPT**: 이미지 및 브랜드 로고 생성
* **Google Flow**: 이미지 기반 영상 생성
* **CapCut**: 영상 생성, TTS·효과음 및 최종 편집
* **OpenAI Sora**: 장면 전환용 음악 생성

## 주요 제작 전략

영상부터 바로 생성하기보다 **이미지를 먼저 완성한 뒤 영상으로 변환**하여 캐릭터와 제품 형태의 불일치를 줄였습니다.

특히 치킨 장면에서 형태가 부자연스럽게 변형되는 문제가 발생해, 이미지를 반복 수정한 뒤 영상으로 변환하고 먹는 소리도 별도로 생성해 적용했습니다.
